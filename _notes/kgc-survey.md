| 锚点 | 年份/出处 | 在领域中的位置 |

## 1 研究背景与任务定义

### 1.1 问题来源

真实知识图谱普遍不完整。以 Wikidata 为例，大量实体缺少关键属性边；DBpedia 的 infobox 抽取也系统性遗漏。不完整性直接损害下游任务（检索、问答、推荐、风控），因此 KGC 的目标是**在不引入人工标注的前提下推断缺失事实**。

KGC 的理论前提是**开放世界假设（Open World Assumption, OWA）**：图中未出现的三元组既非真也非假，只是未知。这一假设带来两个直接后果：

1. 训练时不存在天然负例，必须**构造**负样本（→ 负采样成为核心组件，见 §1.4）；
2. 测试时无法简单判定"未出现即错误"，必须采用**排名式评测**（→ filtered setting，见 §4.2）。

### 1.2 形式化定义

给定知识图谱 $\mathcal{G}=(\mathcal{E},\mathcal{R},\mathcal{T})$，其中 $\mathcal{E}$ 为实体集、$\mathcal{R}$ 为关系集、$\mathcal{T}\subseteq\mathcal{E}\times\mathcal{R}\times\mathcal{E}$ 为三元组集。

**链接预测（Link Prediction）**：给定查询 $(h,r,?)$ 或 $(?,r,t)$，学习打分函数 $f:\mathcal{E}\times\mathcal{R}\times\mathcal{E}\to\mathbb{R}$，使正确实体在全实体集上的排名尽可能靠前。

**三种输出范式**（这一区分在近年文献中常被混淆，需明确）：

| 范式 | 形式 | 代表 | 能否做全实体排名 |
|---|---|---|---|
| 排序（ranking） | 对候选打分并排序 | TransE、RotatE、ConvE | 能，$O(\lvert\mathcal{E}\rvert)$ 次打分 |
| 分类（classification） | 判定三元组真伪 | KG-LLM、SSQR 的分类任务 | 不能，只能给定候选判定 |
| 生成（generation） | 直接解码实体名 | KGT5、KG-LLM | 名义上能，实际受限于解码空间 |

**任务变体**：

- **三元组分类**：给定 $(h,r,t)$ 输出真/假，指标为 Acc / AUC。
- **关系预测**：给定 $(h,?,t)$ 预测 $r$，候选集为全部关系（规模小，难度低于链接预测）。
- **多模态 KGC（MMKGC）**：$\mathcal{G}=(\mathcal{E},\mathcal{R},\mathcal{T},\mathcal{M})$，$\mathcal{M}$ 为图像/文本等模态信息。
- **时序 KGC（TKGC）**：四元组 $(h,r,t,\tau)$，需建模时间有效性。
- **归纳式 KGC（inductive）**：测试时出现训练中未见过的实体，需依赖局部子图或文本而非实体 ID 嵌入。

### 1.3 与相邻任务的边界

| 任务 | 与 KGC 的关系 | 易混淆点 |
|---|---|---|
| KGQA | 下游应用，用 KG 回答自然语言问题 | PoG 属此类；它**隐式**补全缺失链路，但不做链接预测评测 |
| 实体对齐 | 跨图实体匹配，可视为特殊的链接预测 | 目标不是补全单图，而是建立跨图等价关系 |
| 规则挖掘 | 从图中抽取 Horn 规则，与嵌入方法互补 | 规则方法可解释但覆盖低；嵌入方法覆盖高但不可解释 |
| GraphRAG | 把自动构建的 KG 当检索索引，服务于生成 | 其"图"由 LLM 从原文抽取，质量问题的本质与 KGC 同源 |

### 1.4 训练范式：为什么负采样是核心组件

主流 KGC 采用 pairwise ranking loss：

$$
\mathcal{L}=-\log\sigma(\gamma - f(h,r,t))-\sum_{i}\log\sigma(f(h_i',r,t_i')-\gamma)
$$

负样本的质量直接决定梯度的信息量：

- 负样本过于平凡（如"苹果公司的创始人是月亮"）→ 梯度饱和，模型学不到细粒度边界；
- 负样本过于接近正例（假阴性）→ 模型被推向错误方向；
- 负样本分布单一 → 模型只学到粗粒度判别面。

这条线索贯穿：随机采样 → Bernoulli → KBGAN → NSCaching → SANS → MMRNS → DHNS（§3.2）。

## 2 技术路线与分类

### 2.1 三种分类视角

现有综述多按**知识来源**或**模型形式**分类。本笔记补充第三种视角，因为它对判断"方法能否解决某个具体问题"更有解释力。

**视角 A｜按知识来源**

```
结构（三元组拓扑）
文本（实体描述、关系说明）
视觉（实体图像）
时序（时间戳、事件）
参数知识（LLM 内部知识）
```

**视角 B｜按模型形式**

```
几何嵌入（平移/旋转/双曲）
张量分解（双线性/高阶）
神经网络（CNN / RNN / GNN / Transformer）
生成式（seq2seq、扩散）
LLM 适配（微调 / 上下文 / 工具化）
```

**视角 C｜按干预位置**（本笔记主张）

```
训练信号层  ── 改变输入分布（负采样）
表示层      ── 改变实体/关系的编码形式（GNN、量化码、适配器）
输出层      ── 改变预测形式（分类、生成、排名）
推理层      ── 改变调用方式（路径检索、工具调用）
```

视角 C 的价值在于：同一"知识来源"可以落在不同干预位置，效果与成本完全不同。例如文本信息既可进输入序列（KG-LLM），也可进表示层（SSQR），二者代价差一个数量级。

### 2.2 七条主线

| 主线 | 核心假设 | 代表方法 | 主要失效条件 |
|---|---|---|---|
| L1 几何/双线性嵌入 | 关系可由向量运算刻画 | TransE、DistMult、ComplEx、RotatE、PairRE | 长尾实体、未见实体 |
| L2 卷积/图神经网络 | 局部子图蕴含判别信号 | ConvE、R-GCN、CompGCN、GraIL、NBFNet | 稀疏图、深层过平滑 |
| L3 文本增强/语言模型 | 描述文本可补充结构缺失 | KG-BERT、StAR、SimKGC、KGT5 | 描述缺失或噪声大 |
| L4 多模态融合 | 图像提供互补语义 | IKRL、OTKGE、MoSE、NativE、MyGO、TSAM | 模态缺失、模态噪声 |
| L5 负采样/训练信号 | 负样本质量决定判别边界 | KBGAN、NSCaching、SANS、MMRNS、DHNS | 假阴性、生成分布偏移 |
| L6 时序建模 | 事实带时间有效性 | TTransE、HyTE、DE-SimplE、TComplEx | 时间稀疏、事件粒度粗 |
| L7 LLM 融合 | LLM 参数知识可补结构之外 | KG-LLM、KoPA、SSQR、DrKGC、PoG | 成本、可审计性、幻觉 |

### 2.3 演进脉络

```
【嵌入】TransE(2013) → TransH(2014) → TransR/TransD(2015) → RotatE(2019) → QuatE(2019) → PairRE(2021)
                                    ↘ DistMult(2015) → ComplEx(2016) → TuckER(2019)

【神经】ConvE(2018) → InteractE(2020)
        R-GCN(2018) → CompGCN(2020) → GraIL(2020) → NBFNet(2021)   ← 从直推到归纳

【文本】KG-BERT(2019) → StAR(2021) → SimKGC(2022) → KGT5(2022)     ← 从分类到生成

【多模态】IKRL(2017) → MMKG 数据集(2019) → OTKGE(2022) → MoSE(2022) → NativE(2024) → MyGO(2025) → TSAM(2025)

【负采样】随机/Bern(2013) → KBGAN(2018) → NSCaching(2019) → SANS(2020) → MMRNS(2022) → DHNS(2025)

【时序】TTransE(2018)/HyTE(2018) → DE-SimplE(2020) → TComplEx/TNTComplEx(2020)

【LLM】KGT5(2022) → KICGPT(2023) → KoPA(2024) → KG-LLM(2025)/SSQR(2025)/DrKGC(2025)/PoG(2025)
```

**脉络读法**：三条主线在 2022 年后合流——文本线提供"语义入口"，多模态线提供"模态入口"，LLM 线提供"参数知识入口"，三者最终都汇聚到"如何在 LLM 的表示空间里安置 KG"这一问题上（§3.4）。

## 3 代表性方法

### 3.1 打分函数族

| 模型 | 出处 | 打分函数 | 可建模的关系模式 | 备注 |
|---|---|---|---|---|
| TransE | NeurIPS 2013 | $-\|h+r-t\|$ | 反对称、逆、组合 | 无法建模对称；1-to-N 失效 |
| TransH | AAAI 2014 | 超平面投影后平移 | + 1-to-N | 引入关系超平面 |
| TransR | AAAI 2015 | $\|M_rh+r-M_rt\|$ | + 实体/关系异质 | 参数 $O(n_rd^2)$ |
| DistMult | ICLR 2015 | $\langle h,r,t\rangle$ | 仅对称 | 无法区分方向 |
| ComplEx | ICML 2016 | $\mathrm{Re}\langle h,r,\bar t\rangle$ | 对称 + 反对称 | 复向量，无法建模组合 |
| ConvE | AAAI 2018 | 2D 卷积 + 全连接 | 依赖卷积核 | 1-N scoring，效率突破 |
| TuckER | ACL 2019 | 三阶张量分解 | 通用 | 表达力强、参数多 |
| RotatE | ICLR 2019 | $-\|h\circ r-t\|,\ \lvert r_i\rvert=1$ | 对称/反对称/逆/组合 全支持 | 复平面旋转 |
| QuatE | IJCAI 2019 | 四元数 Hamilton 积 | 四种 + 更强表达 | 参数约 4 倍 |
| PairRE | ACL 2021 | $-\|h\circ r_H-t\circ r_T\|$ | 四种 | 每个关系两个向量 |

> **关系模式**是评价几何嵌入的关键维度：对称（$r(x,y)\Rightarrow r(y,x)$）、反对称、逆、组合。RotatE 的贡献正是用旋转把四类统一，这也解释了它为何长期作为 MMKGC 的默认骨架。

### 3.2 负采样方法对比

| 方法 | 出处 | 机制 | 局限 |
|---|---|---|---|
| Uniform | — | 均匀替换头/尾实体 | 大量平凡负例，梯度饱和 |
| Bernoulli | — | 按关系映射性质（1-to-N/N-to-1）调整替换概率 | 仍不看语义 |
| KBGAN | NAACL 2018 | GAN：生成器采样、判别器为 KGE | 训练不稳，依赖预采样分布 |
| NSCaching | AAAI 2019 | 缓存高分负例并动态更新 | 需维护缓存；难度不可控 |
| SANS | AAAI 2020 | 自对抗，按当前模型分数加权 | 依赖模型状态，易自我强化 |
| MMRNS | 2022 | 多模态关系感知的负采样 | 仅改采样分布，不生成 |
| DHNS | DASFAA 2025 | 条件扩散**生成**负嵌入，时间步控硬度，HAL 自适应 margin | 合成样本非真实实体；效率未报告 |

**关键转折**：KBGAN→SANS 属于"先采样再评估难度"，DHNS 属于"按指定难度直接生成"。前者难度是事后度量，后者难度是事前参数。

### 3.3 多模态融合策略

| 策略 | 机制 | 代表 | 风险 |
|---|---|---|---|
| 早期拼接 | 模态特征拼接后送打分器 | IKRL（结构+图像联合空间） | 模态噪声直接污染 |
| 专家乘积（PoE） | 各模态独立打分后相乘 | MMKG 系列 | 需模态对齐 |
| 注意力/门控融合 | 按三元组动态加权模态 | OTKGE、TSAM | 权重难解释 |
| 混合专家（MoE） | 关系感知的专家路由 | MoMoK (ICLR 2025) | 显存开销 |
| 模态 token 化 | 把模态压成 token 序列 | MyGO (AAAI 2025) | 序列长度 |
| 生成式 | 用 T5/VLM 生成或选择 | HERGC (2025) | 训练成本 |
| 鲁棒性建模 | 缺失模态/噪声掩码 | NativE (AAAI 2024)、SNAG | 阈值需标定 |

**核心张力**：结构信息必须在融合中保持主导地位，否则视觉/文本噪声会覆盖拓扑信号。近年趋势是用对比学习把模态特征"拉向"结构嵌入（TSAM、SaCL），而非简单拼接。

### 3.4 LLM 融合的四种耦合深度（本笔记的核心分析框架）

| 耦合位置 | 代表 | 知识形态 | 是否训练 LLM | 主要收益 | 主要代价 |
|---|---|---|---|---|---|
| 输入序列 | KG-LLM、KICGPT、DrKGC | 描述文本 / 检索子图 | 微调或 ICL | 零架构改动 | token 线性增长；逐 KG 微调 |
| 词表与表示 | SSQR、KoPA | 离散码 / 连续前缀 | 两阶段训练 | token 常数（16/实体） | 码不可读；码本封闭 |
| 推理时 | PoG | 图路径 | 不训练 | 可审计、知识即时更新 | 多轮调用；依赖实体链接 |
| 不进入 LLM | DHNS | 连续嵌入 | 仅训练 KGE | 与 LLM 完全解耦 | 不解决语言侧问题 |

**四者的实质差异**：

- **KG-LLM**：把 KGC 改写为 seq2seq，用 LoRA/P-tuning 微调 7B 模型。贡献是证明了"指令微调可弥合描述文本与三元组的鸿沟"，短板是链接预测弱（YAGO3-10 Hits@1 仅 0.133），无法全实体排名。
- **SSQR**：认为鸿沟是**格式**而非语义，用 VQ 码本 + 结构重建 + 语义蒸馏把实体压成 16 个 token。贡献是数量级 token 压缩，短板是码本与任务绑定、码不可审计。
- **KoPA**（ACM MM 2024）：与 SSQR 同属表示层，但走连续前缀适配器路线，把结构特征投影到 token 表示空间置于 prompt 前端。可视为 SSQR 的"连续版"。
- **DrKGC**（EMNLP 2025 Findings）：检索增强 + GCN 适配器，介于 KoPA 与 PoG 之间——既训练轻量结构模型，又把检索子图注入 prompt。
- **PoG**：完全不动参数，用"初始化→探索→三步剪枝→摘要作答"在图上找路径。贡献是可审计与即时更新，短板是推理成本。
- **DHNS**：唯一与 LLM 无关，作用点在负样本分布。

| ICEWS14 / 05-15 | — | — | — | — | — | 时序（事件） |

**数据集的"血统"很重要**：

- FB15k-237 是 FB15k 去掉逆关系泄漏后的版本（Toutanova & Chen, 2015），因此**逆关系类方法在它上面不再占便宜**；
- WN18RR 是 WN18 去掉逆关系冗余后的版本（Dettmers et al., 2018），规模小、关系少，已接近性能天花板；
- 多模态三件套（DB15K / MKG-W / MKG-Y）的图文覆盖率为 70%–98%，**并非全实体有图**，这直接影响模态融合方法的上限。

### 4.2 评测指标

- **MRR**：$\frac{1}{|Q|}\sum_{q}\frac{1}{\text{rank}_q}$，对整体排名敏感。
- **Hits@K**：$\frac{1}{|Q|}\sum_q \mathbb{I}(\text{rank}_q\le K)$，K 常取 1/3/10。
- **Filtered setting**：排名前剔除训练/验证/测试中已出现的其他真三元组（Bordes et al., 2013）。**Raw setting** 不剔除。两者可差 10 个点以上，跨论文比较必须先确认设置。
- **分类任务**：Acc、Precision、Recall、F1、AUC。

### 4.3 评测陷阱（写综述时必须点明）

1. **Filtered 实现不一致**：是否剔除验证集、是否处理重复实体、是否对头尾取平均，各家不同。
2. **测试泄漏**：逆关系、同义关系、数据集构造时的实体重叠（FB15k 的经典问题）。
3. **假阴性**：图中未标注的真三元组被当作负例，系统性压低上限，且对高质量模型惩罚更重。
4. **单次运行、无置信区间**：四篇锚点论文均未报告 CI，小数据集上的 1–2 个点差异可能不显著。
5. **数据集饱和**：WN18RR 上 MRR 已近 0.60，进一步改进空间有限，新方法应转向 FB15k-237 / 大规模 / 归纳设定。
6. **报告口径不一**：绝对增益 vs 相对增益、是否报训练/推理成本、是否报参数量——DHNS 的相对降幅（11.2%）与表中数值重算（10.0%）就不一致。

## 5 各路线优缺点对比

| 路线 | 优势 | 短板 | 适用场景 | 代表 |
|---|---|---|---|---|
| L1 几何/双线性 | 训练快、可解释性中等、生态成熟 | 长尾差、无法利用文本/图像 | 结构完整的中等规模图 | TransE、RotatE、PairRE |
| L2 卷积/GNN | 捕获局部子图、支持归纳 | 稀疏图退化、深层过平滑 | 稠密图、需归纳推理 | ConvE、CompGCN、NBFNet |
| L3 文本/PLM | 缓解冷启动、零样本友好 | 训练贵、描述质量决定上限 | 描述丰富、实体长尾 | KG-BERT、SimKGC、KGT5 |
| L4 多模态 | 补足结构盲区、提升 H@1 | 模态噪声/缺失、融合易失衡 | 图文齐全的领域 KG | OTKGE、NativE、MyGO、TSAM |
| L5 负采样 | 即插即用、不改模型结构 | 假阴性、生成分布偏移、成本 | 任何 pairwise 训练 | SANS、MMRNS、DHNS |
| L6 时序 | 刻画事实有效期 | 时间稀疏、粒度难统一 | 事件流、金融、舆情 | TTransE、DE-SimplE、TComplEx |
| L7 LLM 序列化 | 零架构改动、语义入口宽 | token 线性增长、逐库微调 | 小规模 KG、分类任务 | KG-LLM、KoPA、DrKGC |
| L7 LLM 表示层 | token 常数、推理便宜 | 码不可读、码本封闭 | 大规模 KG、需压缩 | SSQR |
| L7 LLM 工具化 | 可审计、知识即时更新 | 多轮调用、依赖实体链接 | KGQA、需证据链 | PoG |

**横向观察**：表达能力与可审计性基本呈**反向关系**。几何嵌入表达强但不可读，PoG 可读但只在推理时生效，SSQR 处于两者之间且牺牲了可读性换取压缩率。

## 6 当前挑战

### C1 负采样与假阴性
生成式负采样（DHNS）解决了"难度可控"，但引入"合成样本非真实实体"的新问题：模型可能学到"区分合成嵌入与真实嵌入"的捷径，而非语义边界。**目前没有工作量化这一捷径的贡献占比。**

### C2 长尾、少样本与新实体
- 直推式方法（TransE 等）无法处理训练后新增的实体；
- 归纳式方法（GraIL、NBFNet）依赖局部子图，稀疏节点仍失效；
- LLM 路线（KG-LLM）靠参数知识兜底，但不可验证；
- 码本路线（SSQR）对新实体封闭，需重训。

### C3 多模态噪声与缺失模态
真实 MMKG 的图文覆盖率为 70%–98%，缺失模态下的性能衰减可达 20% 以上。现有方法多假设模态齐全，NativE/SNAG 一类"in-the-wild"工作刚开始处理该问题。

### C4 时序与动态演化
绝大多数 KGC 方法假设图静态。时序 KGC 已有时序嵌入（DE-SimplE）与张量分解（TComplEx），但：
- 事件粒度不统一（天/月/年）；
- 外推（未来时间）显著难于插值；
- 与 LLM 的结合几乎空白——**四篇锚点论文无一涉及时间**。

### C5 结构—语言鸿沟与可审计性
把 KG 送入 LLM 的三条路各有代价：文本化（token 爆炸）、离散码（不可读）、路径（依赖链接质量）。**没有任何方案同时做到"高压缩 + 可审计"**。

### C6 评测可信度
领域内普遍缺乏：置信区间、多重比较校正、跨数据集复现、成本报告。这导致大量"提升 1–2 个点"的结论无法区分于噪声。

### C7 LLM 融合的成本—收益
微调 7B 模型的成本与 KGC 的边际收益不匹配；推理时调用（PoG）的成本随问题复杂度线性增长。领域缺少统一的"精度—成本"报告规范。

## 附录 B 与本博客前序工作的接口

本笔记与博客中 LightRAG 实证研究的关系，可归纳为三点：

1. **GraphRAG 中的"图"是自动构建的 KG**，其质量问题（LLM 改写引入的偏差、实体抽取漏检）与 KGC 研究的对象同源；
2. **四篇锚点给出的三条路线在 RAG 场景下的有效性取决于语料规模**：语料小、原文可装下时，任何"替代原文"的压缩表示都不占优（与博客 C1/C2 的结论一致）；
3. **可审计性是可压缩性的对立面**：SSQR 的离散码与 DHNS 的合成嵌入都无法回溯到原文，而 PoG 的路径可以——这提示 GraphRAG 的改进方向应是"抽取式画像 + 路径约束"，而非"更强的压缩表示"。
